📌 Descrição do Projeto

Este simulador calcula a faixa de Imposto de Renda baseada no salário informado e, em seguida, retorna a intensidade da cuspida da Lhama conforme o nível de abuso fiscal sofrido pelo contribuinte.

As regras são simples:
